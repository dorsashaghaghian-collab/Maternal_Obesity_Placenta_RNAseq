# Transcriptomic Analysis of Mouse Placenta Under Maternal Obesity Conditions


## Overview

Maternal obesity is associated with alterations in placental function and fetal development.

In this project, publicly available mouse placental RNA-seq data were analyzed to identify transcriptional changes associated with maternal obesity.


## Dataset

Organism:
Mus musculus

Tissue:
Placenta

Condition:
Maternal obesity vs control


## Bioinformatics Workflow

The analysis workflow included:

- Raw sequencing data processing
- Quality control assessment
- Read alignment
- Gene quantification
- Differential expression analysis using DESeq2
- Visualization of expression changes
- Gene Set Enrichment Analysis (GSEA)


## Differential Expression Results

Differential expression analysis identified Serpine2 as a significantly downregulated gene.

Serpine2:
- log2FC: -1.526
- adjusted p-value: 0.011


## Functional Analysis

GSEA was performed using ranked gene expression statistics to identify biological pathways associated with maternal obesity.


## Biological Interpretation

Serpine2 is involved in extracellular matrix regulation and tissue remodeling.

Reduced Serpine2 expression may indicate alterations in placental extracellular matrix-related processes under maternal obesity conditions.


## Conclusion

This analysis provides a transcriptomic overview of maternal obesity-associated changes in mouse placenta and identifies Serpine2 as a potential candidate gene for further investigation.
